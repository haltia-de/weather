# Погода

Прогноз погоды крупно, на одной странице (`b8k-weather`), для любого города.

- Данные — открытый XML-сервис Gismeteo, значки погоды рисуются программой
  по кодам Gismeteo (их картинки не используются).
- Сейчас: температура, «ощущается как», ветер, давление, влажность, вода,
  восход и закат, магнитное поле. Ниже — по дням с шагом 3 часа; нажатие на
  день открывает его подробно.
- Город выбирается в программе (шестерёнка → «Город», поиск по названию) и
  хранится в `~/.config/b8k/weather.conf`.

## Установка

Нужны Python 3, GTK 3 и PyGObject. В Alpine:

```
apk add python3 py3-gobject3 gtk+3.0
```

Поставить в систему (нужен root):

```
sh install.sh            # в /
sh install.sh /mnt/root  # в другой корень, например при сборке образа
```

`install.sh` кладёт программу в `/usr/local/bin/b8k-weather`, значок и раздел для
панели оболочки в `/usr/local/share/b8k/apps.d/weather.conf`.

## Оболочка планшета

Программа сделана для оболочки
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux)
(Linux на Lenovo YOGA Tablet 10 B8000-H), её сборка ставит программу
отсюда по тегу. Если в системе есть модуль оболочки
`/usr/local/share/b8k/python/b8k_ui.py`, программа берёт из него вибрацию на
нажатия, общий вид заголовка. Без него она работает на любом рабочем
столе с GTK 3.
